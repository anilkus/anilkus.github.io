# Personal Website / Persönliche Website / Kişisel Web Sitesi

## English

This is my personal website, created to share my work, projects, and contact information.

It is a simple static site hosted on GitHub Pages and designed to present my portfolio in a clean and professional way.

### Features
- Personal portfolio page
- Simple and lightweight structure
- Easy to maintain and update
- Hosted on GitHub Pages

### Contact
You can reach out through the contact section on the website or via the links provided in the project.
